## 1. Telling the Hour: 〜じ (ji)

To say the hour, simply add **じ (ji)** to the number. Pay close attention to the irregulars!

  { word: 'ごじ', romaji: 'go-ji', meaning: '5:00', type: 'Time' },
  { word: 'ろくじ', romaji: 'roku-ji', meaning: '6:00', type: 'Time' },
  { word: 'しちじ', romaji: 'shichi-ji', meaning: '7:00 (IRREGULAR)', type: 'Time' },
  { word: 'はちじ', romaji: 'hachi-ji', meaning: '8:00', type: 'Time' },
  { word: 'くじ', romaji: 'ku-ji', meaning: '9:00 (IRREGULAR)', type: 'Time' },
  { word: 'じゅうじ', romaji: 'juu-ji', meaning: '10:00', type: 'Time' },
  { word: 'じゅういちじ', romaji: 'juu-ichi-ji', meaning: '11:00', type: 'Time' },
  { word: 'じゅうにじ', romaji: 'juu-ni-ji', meaning: '12:00', type: 'Time' }

> [!CAUTION]
> - **4 o'clock** is **yo-ji** (never yon-ji or shi-ji).
> - **7 o'clock** is **shichi-ji** (rarely nana-ji).
> - **9 o'clock** is **ku-ji** (never kyuu-ji).

## 2. Telling Minutes: 〜ふん / 〜ぷん (fun / pun)

Minutes are a bit more complex because the pronunciation changes between **fun** and **pun** based on the previous sound.

- **〜ぷん (pun):** 1, 3, 4, 6, 8, 10
- **〜ふん (fun):** 2, 5, 7, 9
- **Half past:** Use **〜じ はん (ji han)**.

## 3. The Time Particle: に (ni)

When an action happens at a *specific* point in time, you must use the particle **に (ni)**.

<GrammarBox client:load 
  pattern="[Time] ＋ に ＋ [Action Verb]"
  meaning="At [time], I do [action]."
  formation="Time + に + Verb"
  examples={[
    { japanese: "しちじ に おきます。", romaji: "Shichi-ji ni okimasu.", translation: "I wake up at 7:00." },
    { japanese: "じゅうにじ に ごはん を たべます。", romaji: "Juu-ni-ji ni gohan o tabemasu.", translation: "I eat a meal at 12:00." },
    { japanese: "じゅういちじ に ねます。", romaji: "Juu-ichi-ji ni nemasu.", translation: "I go to sleep at 11:00." }
  ]}
/>

> [!TIP]
> **When NOT to use に:**
> Do not use **に** with relative time words like "today" (kyou), "tomorrow" (ashita), or "every day" (mainichi). Only use it for specific numbers/calendar points!

<ExampleSentence client:load 
  japanese="くじ に だいがく へ いきます。"
  romaji="Ku-ji ni daigaku e ikimasu."
  translation="I go to the university at 9:00."
/>

<ExampleSentence client:load 
  japanese="どようび に パーティー が あります。"
  romaji="Doyoubi ni paatii ga arimasu."
  translation="There is a party on Saturday."
/>

<ExampleSentence client:load

## 4. Cultural Note: Japanese Punctuality (時間に正確)

Japan is world-famous for its punctuality. This applies to trains, business meetings, and social gatherings.
- **The "5-Minute Rule":** It is often expected that you arrive 5 minutes *before* the scheduled time. Arriving exactly on time is sometimes considered "cutting it close."
- **Train Precision:** Japanese trains are so precise that if a train is delayed by more than a minute, the company may issue a "delay certificate" (*chien-shoumeisho*) for employees to show their bosses.
- **Social Respect:** Being on time is seen as a sign of respect for the other person's time. If you are going to be even 5 minutes late, it is polite to send a message immediately.
