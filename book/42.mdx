Japanese often chooses a different verb depending on where the sentence places its focus. Did a person open the door? Use the transitive verb. Is the door open? Use the intransitive verb. At N3, that distinction helps you understand notices, workplace instructions, and subtle descriptions of result and intention.
</SectionIntro>

## 1. Action on an object or change in the subject?

* **Transitive verbs (他動詞)** describe an agent doing something to an object. The object is commonly marked with `を`.
* **Intransitive verbs (自動詞)** describe a thing changing, appearing, stopping, or being in a state. The thing is commonly marked with `が`.

## 2. 〜ている: action in progress or resultant state

With many action verbs, `〜ている` means an action is in progress: `今、資料を読んでいます` (I am reading the document now). With an **intransitive verb of change**, it often describes the state after the change.

<GrammarBox client:load
  pattern="N が [intransitive verb] ている"
  meaning="N is in the state resulting from the change."
  formation="Use the て-form of an intransitive verb + いる."
  examples={[
    { japanese: "窓が閉まっています。", romaji: "mado ga shimatte imasu.", translation: "The window is closed." },
    { japanese: "会議はもう始まっています。", romaji: "kaigi wa mou hajimatte imasu.", translation: "The meeting has already begun." },
    { japanese: "電気が消えています。", romaji: "denki ga kiete imasu.", translation: "The light is off." }
  ]}
/>

<ExampleSentence client:load
  japanese="駅の前に新しい店ができています。"
  romaji="eki no mae ni atarashii mise ga dekite imasu."
  translation="A new shop has opened in front of the station."
  note="できる is intransitive here: the shop has come into existence and is now there."
/>

## 3. 〜てある: a result intentionally prepared

`〜てある` uses a **transitive** verb. It describes a state that a person intentionally created and left in place, often because it is useful for a purpose. The former object is usually marked with `が` or `は` because the resulting state is now the focus.

<GrammarBox client:load
  pattern="N が / は [transitive verb] てある"
  meaning="N has been done and intentionally left that way."
  formation="Use the て-form of a transitive verb + ある."
  examples={[
    { japanese: "会議の資料は人数分コピーしてあります。", romaji: "kaigi no shiryou wa ninzuubun kopii shite arimasu.", translation: "The meeting handouts have been copied for everyone." },
    { japanese: "予定がカレンダーに書いてあります。", romaji: "yotei ga karendaa ni kaite arimasu.", translation: "The schedule has been written on the calendar." },
    { japanese: "テーブルの上に花が飾ってあります。", romaji: "teeburu no ue ni hana ga kazatte arimasu.", translation: "Flowers have been displayed on the table." }
  ]}
/>

<CommonMistake title="Do not use 〜てある for a natural state">
  <p>`窓が閉まっている` simply describes a closed window. `窓が閉めてある` adds the idea that somebody deliberately closed it and left it closed. Use an intransitive verb with `〜ている` when the agent and purpose are not important.</p>
</CommonMistake>

## 4. 〜ておく: do something in advance

`〜ておく` focuses on the **preparatory action**: do something beforehand, or do it and leave it as it is for later. It can appear as `〜とく` in casual speech.

<GrammarBox client:load
  pattern="V ておく"
  meaning="Do V in advance; do V and leave it that way."
  formation="Verb て-form + おく. Casual speech often shortens it: 調べておく → 調べとく."
  examples={[
    { japanese: "旅行の前に、ホテルを予約しておきます。", romaji: "ryokou no mae ni, hoteru o yoyaku shite okimasu.", translation: "I will reserve the hotel before the trip." },
    { japanese: "忘れないように、必要な書類を机に置いておいた。", romaji: "wasurenai you ni, hitsuyou na shorui o tsukue ni oite oita.", translation: "I put the necessary documents on the desk beforehand so I would not forget them." },
    { japanese: "後で見られるように、リンクを保存しておいて。", romaji: "ato de mirareru you ni, rinku o hozon shite oite.", translation: "Save the link so that we can look at it later." }
  ]}
/>

**Quick contrast:** `資料がコピーしてある` describes the ready handouts; `資料をコピーしておく` describes the action of copying them beforehand.

<CultureNote title="Descriptions that reduce blame" ja="表現">
  <p>When reporting an accident or an inconvenient change, Japanese often uses an intransitive verb such as <strong>コップが割れました</strong> (“The glass broke”). This can keep the focus on the event rather than immediately naming a person. It does not erase responsibility; it simply changes the sentence's perspective.</p>
</CultureNote>

## 7. Reading practice: library notice

> 来週の読書会は二階の会議室で行います。部屋の入口に参加者の名札が置いてありますので、来た人は自分の名札を取ってください。資料は会議の前日に印刷しておきます。窓が開いていたら、閉めてください。

**Reading check:** Find one example each of (1) `〜てある`, (2) `〜ておく`, and (3) an intransitive verb. What information does each one emphasize?

Translation: “Next week's reading group will be held in the second-floor meeting room. Participants' name tags have been placed at the room entrance, so please take your own when you arrive. We will print the materials the day before the meeting. If the window is open, please close it.”
