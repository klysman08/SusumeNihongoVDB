## 1. Personal Pronouns

While English uses pronouns constantly, Japanese often omits them if it is obvious who is speaking.

<VocabTable data={[
  { word: 'わたし', romaji: 'watashi', meaning: 'I / Me (Standard)', type: 'Pronoun' },
  { word: 'あなた', romaji: 'anata', meaning: 'You (Use sparingly)', type: 'Pronoun' },
  { word: 'かれ', romaji: 'kare', meaning: 'He / Boyfriend', type: 'Pronoun' },
  { word: 'かのじょ', romaji: 'kanojo', meaning: 'She / Girlfriend', type: 'Pronoun' },
  { word: 'わたしたち', romaji: 'watashitachi', meaning: 'We', type: 'Pronoun' }

> [!TIP]
> Instead of saying "You" (anata), it is much more polite and common in Japan to refer to someone by their **Name + Honorific** (e.g., Tanaka-san).

## 2. Demonstrative Pronouns (Ko-So-A-Do)

Japanese uses a systematic way to point at things based on their distance from the speaker and listener.

- **これ (Kore):** This (Near the speaker)
- **それ (Sore):** That (Near the listener)
- **あれ (Are):** That over there (Far from both)
- **どれ (Dore):** Which one? (Question)

<GrammarBox client:load 
  pattern="これ / それ / あれ ＋ は ＋ [Noun] ＋ です"
  meaning="Identifying objects based on distance."
  formation="Pronoun + は + Noun + です"
  examples={[
    { japanese: "これ は わたし の 本 です。", romaji: "Kore wa watashi no hon desu.", translation: "This is my book." },
    { japanese: "それ は なん です か。", romaji: "Sore wa nan desu ka.", translation: "What is that (near you)?" },
    { japanese: "あれ は 先生 の 車 です。", romaji: "Are wa sensei no kuruma desu.", translation: "That over there is the teacher's car." }
  ]}
/>

## 3. The "Also" Particle: も (mo)

The particle も (mo) means "also" or "too". It is unique because it **replaces** the particles は (wa), が (ga), and を (o).

<GrammarBox client:load 
  pattern="[Noun] ＋ も"
  meaning="Expresses 'also' or 'too'."
  formation="Noun + も (Replaces は, が, を)"
  examples={[
    { japanese: "わたし は 学生 です。 アリさん も 学生 です。", romaji: "Watashi wa gakusei desu. Ari-san mo gakusei desu.", translation: "I am a student. Ali is ALSO a student." },
    { japanese: "これ は ペン です。 それ も ペン です。", romaji: "Kore wa pen desu. Sore mo pen desu.", translation: "This is a pen. That is also a pen." },
    { japanese: "りんご を たべます。 バナナ も たべます。", romaji: "Ringo o tabemasu. Banana mo tabemasu.", translation: "I eat apples. I also eat bananas." }
  ]}
/>

## 4. Cultural Note: Japanese Names & Honorifics

In Japan, you rarely call someone by their first name unless you are very close. Usually, you use their **Family Name + Honorific**.
- **-san (さん):** The most common honorific, equivalent to Mr., Ms., or Mrs. Use it for almost everyone.
- **-kun (君):** Typically used for boys or by superiors to subordinates.
- **-chan (ちゃん):** A cute honorific used for children, female friends, or pets.
- **-sama (様):** Extremely formal, used for customers or deities.

Never use an honorific on your own name! It sounds very arrogant.
