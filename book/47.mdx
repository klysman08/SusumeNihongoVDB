## 2. Deliberate effort and resulting change

<PatternCompare client:load title="Effort versus achieved change" items={[
  { pattern: "V-る／V-ないようにする", meaning: "make an effort to; take care to", use: "A continuing, deliberate practice. It does not guarantee success.", example: "会議では、結論から話すようにしています。", translation: "In meetings, I make a point of stating the conclusion first.", register: "deliberate" },
  { pattern: "V-る／V-ないようになる", meaning: "come to; reach a changed state", use: "Describes a new ability, habit, or state that has developed.", example: "練習して、敬語が少し使えるようになった。", translation: "Through practice, I have become able to use some honorific language.", register: "result" }
]} />

<CommonMistake title="Effort is not the same as success"><p><strong>忘れないようにしています</strong> means “I make an effort not to forget.” <strong>忘れないようになりました</strong> means the change has actually occurred: “I no longer tend to forget.”</p></CommonMistake>
