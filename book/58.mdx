<SectionIntro level="N3">Sequence is not only “before” and “after.” These forms show whether an event is formal, sudden, newly revelatory, a strict prerequisite, or possible only within a limited window.</SectionIntro>

<CommonMistake title="とたん is not a planned sequence"><p><strong>家に着いたとたん、電話が鳴った</strong> is natural because the call is sudden. For a deliberate next action, use <strong>家に着いてから、電話した</strong>.</p></CommonMistake>
